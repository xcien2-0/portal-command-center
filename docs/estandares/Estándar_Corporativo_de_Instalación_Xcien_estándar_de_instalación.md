## 1. Objetivo del Documento

El presente Estándar Corporativo de Instalación Xcien tiene como objetivo establecer un proceso sistematizado, estandarizado y profesional para la entrega de servicios de telecomunicaciones. Este documento define los pasos, reglas y requisitos esenciales para asegurar la calidad, la seguridad operativa y la satisfacción del cliente en cada instalación, contribuyendo al cumplimiento de la meta de estandarización y profesionalización de Xcien.

## 2. Alcance

Este estándar es de aplicación obligatoria para todo el personal técnico de Xcien y sus empresas filiales (HUUS, LUMINET WAN, SENEL), así como para los equipos de Dispatch, Ventas y Preventa involucrados en la planificación, ejecución y validación de las instalaciones de servicios. Cubre todas las fases del proceso, desde la recepción de la tarea hasta la validación final y documentación, para garantizar la consistencia y excelencia en la entrega de cualquier tipo de servicio ofrecido por Xcien que requiera instalación en sitio.

## 3. Glosario

*   **AD (Alta Disponibilidad):** Tipo de servicio diseñado para minimizar el tiempo de inactividad.
*   **Ancho de Banda:** Capacidad de una conexión para transferir datos en un período determinado.
*   **AP (Access Point):** Dispositivo que crea una red de área local inalámbrica.
*   **Arnés a 5 puntos de anclaje:** Equipo de protección personal para trabajos en altura que distribuye la fuerza de impacto en caso de caída.
*   **Cableado Estructurado:** Infraestructura de cableado organizada que soporta múltiples sistemas de comunicación.
*   **CDD (Cambio de Domicilio):** Proceso de reubicación de un servicio existente.
*   **COR:** Centro de Operaciones de Red.
*   **Decibel (dbi):** Unidad de medida utilizada para expresar la relación de niveles de potencia de la señal.
*   **Demarcador / Punto de Demarcación:** Punto físico donde termina la responsabilidad del proveedor de servicios y comienza la del cliente.
*   **DHCP (Dynamic Host Configuration Protocol):** Protocolo de red que asigna automáticamente direcciones IP a los dispositivos.
*   **Dispatch:** Área encargada de la asignación y seguimiento de tareas a los equipos técnicos.
*   **Empotrado:** Tipo de instalación donde la infraestructura (mástil) se fija directamente a una estructura vertical (ej. pretil).
*   **EPP (Equipo de Protección Personal):** Conjunto de elementos que el trabajador debe utilizar para protegerse de riesgos laborales.
*   **Espárrago:** Varilla roscada utilizada para fijación.
*   **Gateway:** Dispositivo que actúa como puerta de enlace entre redes diferentes.
*   **GPS (Sistema de Posicionamiento Global):** Sistema de navegación y localización por satélite.
*   **Habilitación:** Verificación o confirmación de que un servicio o tarea puede ser ejecutada.
*   **Herraje tipo V:** Elemento de fijación en forma de "V" utilizado para asegurar mástiles.
*   **IP (Internet Protocol):** Identificador numérico único asignado a cada dispositivo en una red.
*   **IP Fija:** Dirección IP que se asigna permanentemente a un dispositivo.
*   **Línea de Vida:** Sistema de seguridad que permite la conexión del arnés a un punto de anclaje seguro.
*   **LV (Línea de Vista):** Trayectoria despejada y sin obstrucciones entre dos puntos, esencial para comunicaciones inalámbricas.
*   **Maqueta:** Instalación provisional de equipo para validar la factibilidad técnica y los valores de señal del servicio.
*   **Máscara de Red:** Número que determina qué parte de una dirección IP se refiere a la red y qué parte al host.
*   **Mástil:** Estructura vertical utilizada para elevar antenas o radios.
*   **Odoo:** Sistema de gestión empresarial utilizado para la administración de tareas.
*   **Pija Broca:** Tornillo autoperforante.
*   **POE (Power over Ethernet):** Tecnología que permite que los cables de red transporten energía eléctrica.
*   **Pretil:** Muro bajo que se construye en el borde de una azotea o terraza.
*   **Preventa:** Área encargada de evaluar la factibilidad técnica de un servicio antes de la venta.
*   **RB (Radio Base):** Infraestructura donde se aloja el equipo de transmisión y recepción de radiofrecuencia.
*   **Router:** Dispositivo que reenvía paquetes de datos entre redes de computadoras.
*   **S.E. (Servicio Externo):** Tarea asignada para ser realizada fuera de las instalaciones de Xcien, usualmente en el sitio del cliente.
*   **SENEL:** Empresa filial de Xcien.
*   **SIDP (Servicio Internet Dedicado Plus):** Servicio de internet dedicado de alto rendimiento.
*   **SIEV (Servicio Eventual):** Servicio de internet por un período limitado.
*   **SIMP (Servicio Internet Mye Plus):** Servicio de internet.
*   **SIS (Servicio Internet Satelital):** Servicio de internet vía satélite.
*   **Site:** Localización física donde se instala el equipo principal del cliente.
*   **SRPVD (Servicio Red Privada Virtual Dedicada):** Servicio de red privada virtual con recursos exclusivos.
*   **SSID (Service Set Identifier):** Nombre de una red inalámbrica.
*   **SSTC (Servicio de Soporte Técnico):** Servicio de asistencia técnica.
*   **Sujetadores Mecánicos:** Dispositivos utilizados para asegurar elementos a una superficie, especialmente láminas.
*   **Taquete Expansor:** Elemento de fijación que se expande dentro de un orificio para anclar.
*   **Tensado:** Tipo de instalación donde la infraestructura (mástil) se asegura mediante cables tensores para mantener su estabilidad.
*   **Tensor:** Dispositivo utilizado para ajustar la tensión de un cable o alambre.
*   **VOIP (Voz sobre IP):** Tecnología que permite realizar llamadas de voz a través de internet.
*   **Xcien:** Empresa matriz de telecomunicaciones.

## 4. Desarrollo del Proceso / Procedimiento Paso a Paso

El proceso de instalación de servicios de Xcien se divide en etapas secuenciales, diseñadas para garantizar una ejecución eficiente, segura y de alta calidad.

### 4.1. Recepción y Análisis de Tarea (Odoo)

1.  **Verificación de Habilitación:** El equipo técnico debe verificar la habilitación de la tarea de instalación a través de su herramienta de trabajo (celular) en la plataforma Odoo.
2.  **Análisis de Requerimientos Iniciales:** Se debe revisar detalladamente la tarea en Odoo, la cual contiene la siguiente información crítica:
    *   Título de la tarea
    *   Tipo de tarea
    *   Nombre completo del cliente
    *   Dirección de instalación y/o coordenadas exactas
    *   Tipo de servicio a entregar
    *   Fecha y horario de visita programado
    *   Nombre y contacto en sitio
    *   Resumen del diagnóstico o indicaciones previas proporcionadas por las áreas de Ventas o Preventa.

### 4.2. Revisión de Equipo de Protección Personal (EPP) y Herramientas

1.  **Preparación de EPP:** Antes de iniciar el trayecto al sitio, el técnico debe asegurarse de contar con el uniforme completo y la totalidad del Equipo de Protección Personal (EPP) requerido, en óptimas condiciones:
    *   Uniforme completo de Xcien.
    *   Zapatos de seguridad.
    *   Chaleco de seguridad.
    *   Casco de seguridad con barbiquejo.
    *   Guantes para trabajo.
    *   Arnés de seguridad a 5 puntos de anclaje.
    *   Línea de vida para seguridad del trabajador.
    *   Línea de vida de ganchos dobles para ascenso.
2.  **Verificación de Herramientas:** Confirmar que se dispone de todas las herramientas necesarias y que estas se encuentran en perfecto estado de funcionamiento.

### 4.3. Solicitud de Requerimientos y Materiales

1.  **Identificación de Equipamiento:** En esta fase, se debe solicitar el equipamiento y/o materiales específicos y correspondientes para la correcta realización de la entrega del servicio, con base en el análisis de la tarea en Odoo.
    *   **Ejemplos de Requerimientos:**
        *   Radios
        *   Routers
        *   Mástiles (Básicos o Telescópicos)
        *   Cableado
        *   Access Points (AP's)
        *   Tuberías
        *   Otros materiales específicos del sitio.
2.  **Detalle de Requerimientos:** Para cada solicitud, se deberá especificar:
    *   **Tipo o Nombre de Requerimiento:** (Ej. radios, router, antenas, POE, etc.).
    *   **Descripción:** Breve explicación de la función o necesidad del requerimiento.
    *   **Orden de Compra:** Folio asignado para el procesamiento y adquisición del equipo/material.

### 4.4. Trayecto al Sitio del Cliente

1.  **Seguimiento de Indicaciones:** Es obligatorio seguir las indicaciones de dirección y/o coordenadas brindadas en la tarea S.E. de Odoo, previamente corroboradas por el personal de Dispatch.
2.  **Comunicación Continua:** Es responsabilidad conjunta del técnico y del personal de Dispatch mantener una comunicación constante, brindando y actualizando los tiempos estimados de trayecto y llegada al cliente.
3.  **Uso de GPS:** Utilizar sistemas de navegación GPS para asegurar la llegada precisa al sitio.
4.  **Detalles del Sitio:** Revisar la sección de "Descripción" en Odoo para obtener detalles específicos que ayuden a la ubicación y asistencia correcta en el sitio.

### 4.5. Presentación y Planificación con el Cliente

1.  **Presentación con el Cliente:**
    *   Presentarse siempre con cordialidad y una excelente imagen corporativa, indicando la empresa de la que se procede (XCIEN, HUUS, LUMINET WAN, SENEL).
    *   **Guion de Presentación:** "Buenos días (tardes), mi nombre es [Nombre del Técnico] de la Empresa [Nombre de Empresa]. Vengo a realizar la Instalación de su servicio de Internet, el cual es [Ejemplo de Servicio y sus siglas, Ej. SIDP-30, Sandur, TRANSPORTES LAR MEX]."
        *   **Nomenclaturas de Servicio Comunes:**
            *   SIDP: Servicio Internet Dedicado Plus
            *   VOIP: Servicio Voz IP
            *   SIEV: Servicio Eventual
            *   AD: Alta Disponibilidad
            *   SRPVD: Servicio Red Privada Virtual Dedicada
            *   SIMP: Servicio Internet Mye Plus
            *   CDD: Cambio de Domicilio
            *   SIS: Servicio Internet Satelital
            *   SSTC: Servicio de Soporte Técnico
2.  **Explicación del Trabajo:** Explicar detalladamente el proceso de instalación al cliente:
    *   Método de instalación (acceso a azotea, escalera marina o uso de escalera propia).
    *   Ubicación del router o punto de demarcación.
    *   Validar la trayectoria de cableado desde la instalación en azotea hasta el site o punto de demarcación, confirmando el acceso por tubería o paso de muro.
3.  **Procedimiento General de Instalación:** Informar al cliente sobre las fases de la instalación:
    *   **Fase 1:** Revisión completa de la mejor ubicación y materiales requeridos (corroborado con el cliente).
    *   **Fase 2:** Instalación de mástil con radio en la azotea.
    *   **Fase 3:** Cableado del radio hacia el router en el site o punto indicado por el cliente.
    *   **Fase 4:** Instalación y configuración del router.
4.  **Tiempo Aproximado:** Informar al cliente el tiempo aproximado estimado para la instalación.
5.  **Revisión en Sitio:** Realizar una revisión conjunta con el cliente para identificar cualquier material especial o requerimiento particular del sitio.
6.  **Preparación para Alturas:** Prepararse para subir a la azotea, asegurando el uso de escalera, arnés, casco, línea de vida y todo el EPP necesario para trabajar de manera segura.

### 4.6. Proceso de Instalación en Sitio

#### 4.6.1. Evaluación de Línea de Vista (LV)

1.  **Punto Más Alto:** Ascender al punto más alto y con suficiente espacio para realizar la instalación factible.
2.  **Ubicación de la LV:** Basado en la información de la tarea S.E., se debe ubicar la línea hacia la Radio Base (RB) de la que depende el servicio.
3.  **Definición de Maqueta vs. Instalación Directa:** En esta etapa se define si se realizará una maqueta o se procederá directamente a la instalación de la infraestructura, lo cual se determina mediante la evaluación de la LV y el relieve hacia la RB.
4.  **Validación de Requerimientos de Infraestructura:** Validar los elementos necesarios para la instalación (empotrado, tensado) o cualquier infraestructura especial (ej. opresores para lámina de ceja).

#### 4.6.2. Maqueta y Validación de Servicio

1.  **Definición de Maqueta:** Consiste en la instalación provisional del equipo en la punta del mástil para validar que se obtienen los valores de señal requeridos para la entrega del servicio.
2.  **Maqueta e Instalación Factible:**
    *   Si se detecta alguna obstrucción o la LV está comprometida, se procederá a realizar una maqueta para validar el servicio.
    *   Una vez que la maqueta se realiza de manera exitosa y se tiene la altura requerida para un servicio de calidad y óptimas condiciones, se procederá a realizar la instalación como se había previsualizado (empotrado o tensado).
    *   Si la LV es franca hacia la RB, la altura en sitio es la requerida y no se detectan obstrucciones (según el resultado del aprovisionamiento), no será necesario realizar una maqueta y se procederá directamente con la instalación.
3.  **Maqueta e Instalación No Factible:**
    *   Si la maqueta del servicio no es factible (ni con mástil de 3m ni de 6m), se deberá validar la situación con Aprovisionamiento, Preventa y COR (opcional) para definir el paso a seguir.
    *   Proporcionar retroalimentación detallada del sitio: altura total de la construcción, tipo de caseta o nave industrial, realizar levantamiento del sitio (altura, espacio disponible para instalar, tipo de estructura, trayectoria de cableado, ubicación para router/demarcación y LV).
    *   En caso de no encontrar una solución en sitio, se regresará la tarea al área de Preventa para la revisión de la factibilidad del sitio.
    *   Una vez que la maqueta no ha sido exitosa y se ha validado con Aprovisionamiento y Preventa que no se pudo dar otra solución en sitio (otro punto de instalación, otra RB, etc.), el personal técnico procederá a retirarse del sitio.

#### 4.6.3. Puntos para una Instalación Segura (Infraestructura)

Se deben considerar los siguientes puntos para asegurar la estabilidad y seguridad de la infraestructura instalada:
*   Área para instalación segura.
*   Tipo de instalación (Empotrado/Tensado).
*   Ángulos de anclaje seguros.
*   Anclaje seguro.
*   Ángulo de retenida (45° o mínimo la mitad de la altura instalada).
*   Altura de retenida (aproximadamente 15 cm debajo de la punta de cada sección de mástil).
*   Trayectoria de cableado segura y organizada.
*   Tipo de servicio a instalar.
*   Revisión y validación de voltajes correctos.

##### 4.6.3.1. Infraestructura Empotrada (3 metros máximo)

*   Contar con LV totalmente franca hacia la RB.
*   Contar con al menos 80 cm de pretil disponible para anclaje.
*   Utilizar 2 herrajes tipo V con una separación mínima de 30 cm entre ellos.
*   Reforzar del herraje al mástil con pija broca.
*   El mástil debe quedar perfectamente nivelado.
*   El radio se instalará a 2.5 mts del mástil.
*   El cableado debe ir encinchado cada 50 cm en el mástil, dejando 1 metro de resguardo a la altura del radio y 2 metros adicionales en la parte inferior del mástil.
*   La altura total del mástil no debe exceder los 3 metros.

##### 4.6.3.2. Infraestructura Tensada 3 metros (sobre losa de concreto)

*   Área mínima para instalación de 3 metros cuadrados.
*   3 anclajes con espárrago y taquete expansor al pretil, utilizando alambre y tensor, al menos a 1.5 a 2 metros de separación de la base del mástil y a 120° entre cada uno.
*   Ángulo de 45° en las retenidas, a 2 metros de altura del mástil.
*   Doble herraje V y 2 espárragos para la sujeción de las retenidas al mástil, reforzando con pija broca para evitar deslizamientos al tensar.
*   El cableado debe ir encinchado cada 50 cm y con un resguardo de 1 metro a la altura del radio y 2 metros en la base del mástil.

##### 4.6.3.3. Infraestructura Tensada 3 metros (sobre lámina)

*   Área mínima para instalación de 3 metros cuadrados.
*   3 anclajes con sujetadores mecánicos, utilizando alambre y tensor, al menos a 2 metros de la base del mástil y a 120° entre cada uno.
*   Ángulo de 45° en las retenidas, a 2 metros de altura del mástil.
*   Doble herraje V y 2 espárragos para la sujeción de las retenidas al mástil, reforzando con pija broca para evitar deslizamientos al tensar.
*   El cableado debe ir encinchado cada 50 cm y con un resguardo de 1 metro a la altura del radio y 2 metros en la base del mástil.

##### 4.6.3.4. Infraestructura Tensada 6 metros (sobre losa de concreto)

*   Área mínima para instalación de 4 metros cuadrados.
*   3 anclajes con espárrago y taquete expansor al pretil, utilizando alambre y tensor, al menos a 2.5 metros de la base del mástil y a 120° cada uno.
*   Ángulo de 45° en las retenidas, la primera a los 2.5 metros y la segunda a los 5 metros del mástil.
*   Doble herraje V y 2 espárragos para la sujeción de las retenidas al mástil en ambos puntos, reforzando con pija broca para evitar deslizamientos al tensar.
*   El cableado debe ir encinchado cada 50 cm y con un resguardo de 1 metro a la altura del radio y 2 metros en la base del mástil.

##### 4.6.3.5. Infraestructura Tensada 6 metros (sobre lámina)

*   Área mínima para instalación de 4 metros cuadrados.
*   3 anclajes con sujetadores mecánicos, utilizando alambre y tensor, al menos a 2.5 metros de la base del mástil y a 120° entre cada uno.
*   Ángulo de 45° en las retenidas, la primera a los 2.5 metros y la segunda a los 5 metros del mástil.
*   Doble herraje V y 2 espárragos para la sujeción de las retenidas al mástil en ambos puntos, reforzando con pija broca para evitar deslizamientos al tensar.
*   El cableado debe ir encinchado cada 50 cm y con un resguardo de 1 metro a la altura del radio y 2 metros en la base del mástil.

##### 4.6.3.6. Mástil Telescópico 12 metros (sobre losa de concreto)

*   Área mínima para instalación de 6 metros cuadrados.
*   3 anclajes tipo aleta con retenida de 1/8 y tensores, al menos a 5 metros de la base del mástil y a 120° cada uno.
*   Ángulo de 45° en las retenidas, la primera a los 3 metros, la segunda a los 6 metros, la tercera a los 9 metros y la cuarta a los 12 metros del mástil.
*   4 porta retenidas para la sujeción de las retenidas al mástil, las cuales deben instalarse por encima del tornillo de ajuste para evitar deslizamientos al tensar.
*   El cableado debe ir encinchado cada 1 metro y con un resguardo de 3 metros en la base del mástil.

##### 4.6.3.7. Mástil Telescópico 12 metros (sobre lámina)

*   Área mínima para instalación de 6 metros cuadrados.
*   6 anclajes con sujetador mecánico a la lámina de ceja; los primeros dos a 3 metros para las primeras dos retenidas, y los siguientes dos a 5 metros para la tercera y cuarta retenida, utilizando retenida de 1/8 y tensores, y a 120° entre cada uno.
*   Ángulo de 45° en las retenidas, la primera a los 3 metros, la segunda a los 3 metros, la tercera a los 9 metros y la cuarta a los 12 metros del mástil.
*   4 porta retenidas para la sujeción de las retenidas al mástil, las cuales deben instalarse por encima del tornillo de ajuste para evitar deslizamientos al tensar.
*   El cableado debe ir encinchado cada 1 metro y con un resguardo de 3 metros en la base del mástil.

#### 4.6.4. Trayectoria de Cableado

1.  **Cableado Expuesto:** Si el cableado va expuesto, se debe buscar la manera más segura para su trayecto desde la base del mástil hacia un pretil cercano a la bajada del cableado estructurado. Cada vuelta del cableado debe ser asegurada con grapas o cinchos:
    *   Cinchado: cada 2 metros.
    *   Grapado: cada 1 metro.
2.  **Cableado por Tubería:** Si el cableado se instala por tubería, asegurarse de que la trayectoria de la tubería sea segura y no contenga agua.

### 4.7. Configuración y Pruebas del Servicio

#### 4.7.1. Configuración de Radios

1.  Una vez instalado y cableado el servicio hasta el router, se procede a realizar la configuración básica del radio (SSID, llave, IP, máscara y gateway).
2.  Verificar que el equipo se enlace correctamente, lo cual es el paso previo a la alineación.

#### 4.7.2. Alineación de Radios

1.  Una vez que el/los radios están enlazados, se procede a realizar la alineación del equipo para encontrar la mejor señal y capacidad.
2.  Después de lograr la mejor alineación, se procede a la configuración del router, validando previamente con el cliente el tipo de entrega requerido (DHCP o IP fija).

#### 4.7.3. Niveles de Señal

Es mandatorio que los niveles de señal del enlace se encuentren dentro de los rangos de tolerancia establecidos para garantizar la calidad del servicio.

| Rango de Señal (dbi) | Calidad del Enlace |
| :------------------- | :----------------- |
| 35-45                | Excelente          |
| 45-55                | Bueno              |
| 55-65                | Regular            |
| 65-75                | Alto               |
| 75-85                | Malo               |

#### 4.7.4. Pruebas de Velocidad

1.  Después de la configuración del router, se deben realizar pruebas de velocidad ilimitadas para validar el ancho de banda que entrega el enlace.
2.  Posteriormente, se limita el servicio a la velocidad contratada por el cliente.
3.  Se realizan pruebas de velocidad limitadas para confirmar la correcta entrega del servicio.
4.  Finalmente, se valida la velocidad con el cliente y se procede a liberar el servicio.

### 4.8. Documentación y Cierre de Servicio

#### 4.8.1. Documentación en Odoo

1.  **Hoja de Trabajo:** Es obligatorio completar la hoja de trabajo en Odoo, detallando el listado de materiales consumibles utilizados en el sitio.
2.  **Firma del Cliente:** Recolectar la firma de conformidad del cliente en la hoja de trabajo.
3.  **Evidencia Fotográfica:** Anexar imágenes claras y relevantes a la tarea en Odoo, que documenten la instalación realizada y la conformidad del cliente.

#### 4.8.2. Revisión Final y Retiro del Sitio

1.  **Llamada de Calidad:** Validar con el dispatcher la llamada de calidad, asegurándose de que se realiza estando aún en el sitio del cliente.
2.  **Limpieza del Sitio:** Validar que no se haya dejado ningún tipo de basura o residuo en el sitio de instalación.
3.  **Atención al Cliente:** Aplicar siempre los principios y habilidades aprendidas en el curso de atención al cliente.
4.  **Confirmación de Salida:** Validar la salida del sitio con el dispatcher.
5.  **No Retirarse sin Documentar:** Bajo ninguna circunstancia se debe abandonar el sitio sin haber documentado la tarea correspondiente en Odoo.
6.  **Recolección de Equipo:** Al finalizar, se debe proceder a recoger toda la herramienta y las escaleras utilizadas en el sitio.

## 5. Reglas de Seguridad o Tolerancia Cero

La seguridad de nuestro personal, de nuestros clientes y de la infraestructura es de máxima prioridad en Xcien. El incumplimiento de estas reglas es considerado una falta grave.

1.  **Uso Obligatorio de EPP:** Es de *TOLERANCIA CERO* el no utilizar el Equipo de Protección Personal (EPP) completo y en perfectas condiciones (uniforme, zapatos, chaleco, casco con barbiquejo, guantes, arnés a 5 puntos, líneas de vida) durante todo el tiempo que dure el trabajo en campo, especialmente en alturas.
2.  **Inspección Previa de EPP:** Todo el EPP debe ser inspeccionado antes de cada uso para asegurar su buen estado y funcionalidad. Se prohíbe el uso de EPP dañado o defectuoso.
3.  **Trabajo en Alturas:**
    *   Se requiere el uso continuo del arnés de seguridad anclado a una línea de vida doble durante ascenso, permanencia y descenso en alturas.
    *   Verificar la estabilidad de escaleras y estructuras antes de utilizarlas.
    *   Mantener tres puntos de contacto al subir o bajar escaleras.
4.  **Áreas de Trabajo Seguras:**
    *   Delimitar adecuadamente las áreas de trabajo para prevenir accidentes a terceros.
    *   Verificar la estabilidad de techos, azoteas o cualquier estructura donde se realizará la instalación.
    *   Realizar revisión de voltajes con equipo adecuado antes de manipular cualquier conexión eléctrica.
